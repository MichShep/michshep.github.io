Personal Project · Aug 2025 – Present

War of the Ring

A networked, server-authoritative digital adaptation of the War of the Ring board game, built solo. Accumulating into a 25,000-line C# codebase in Unity 6, split across 7 independently-compiled assemblies with enforced dependency boundaries.

Key Features

Node-Based Rules Engine

Designed a composable, node-based rules engine (effectively a lightweight visual scripting system built from scratch) where every game action is assembled from a library of 60 reusable nodes, letting an entire board game's ruleset be authored without writing new code.

C# Rules Engine Tooling

Server-Authoritative Multiplayer

Implemented server-authoritative multiplayer, validating actions server-side and broadcasting only resulting state deltas to minimize network traffic and guarantee client-server consistency.

Networking System Design

Data-Driven Content System

Architected a data-driven, configuration-based content system with 265+ structured data assets, decoupling application logic from content and enabling non-engineers to modify behavior without touching code.

Data-Driven Architecture Content Tools
