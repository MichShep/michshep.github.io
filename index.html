Insane Space Survival – Unity

A systemic space survival game built in Unity focused on cascading disasters, oxygen management, and player-driven recovery under pressure. Players must stabilize a failing ship while reacting to meteor storms, radiation bursts, hull breaches, and self-destruct sequences.

The project emphasizes readable UI, feedback-driven mechanics, and disaster tuning so that outcomes feel tied to player decisions rather than randomness. Key systems include procedural ship generation, air flow simulation, event-driven disaster planning, and helmet-based HUD feedback.

My contributions: full gameplay architecture, procedural generation system, disaster planner logic, oxygen simulation, UI feedback systems, tutorial flow, and gameplay tuning.

Legend of Zelda Remake + “Twin Chain Trial”

A recreation of classic Zelda gameplay mechanics built in Unity, featuring player combat, enemy AI, knockback systems, room transitions, and item usage. The project culminates in a custom dungeon called “Twin Chain Trial,” designed around an original mechanic inspired by the Blade of Chaos.

The new mechanic introduces a hold-to-extend chained blade and simultaneous dual-button activation puzzles. The dungeon layout forces players to commit to extended attacks, manage vulnerability windows, and make positioning-based combat decisions rather than relying on quick sword taps.

My contributions: combat systems, knockback logic, half of the enemy AI, full player and enemy sprite animation logic (directional sprite sets, sprite state transitions, frame timing control, and hit-flash effects), custom chained-blade mechanic implementation, dungeon layout design, and debugging edge cases involving timing, physics interactions, and simultaneous input coordination.

    • Resonant – Game Boy Advance Project

    Resonant is an original Game Boy Advance game developed in C with hardware-level control over sprites, palettes, tiles, and memory. The game explores a post-apocalyptic world centered around energy-themed creatures called SoulNodes.

    The project includes custom sprite systems, animation lookup tables, pathfinding, collision grids, dialogue rendering, and optimized memory usage tailored to GBA constraints. A major focus was efficient rendering and clean system architecture under hardware limitations.

    Current Systems: core engine architecture, sprite management, animation LUT system, collision detection, NPC movement logic, text rendering pipeline, and hardware-conscious optimization.

    Pix2GBA – Sprite & Palette Conversion Tool

    Pix2GBA is a custom tool built to convert images into Game Boy Advance–compatible tiles and palettes. It supports meta-tile sizing, palette generation, and efficient tile extraction for use in hardware-based GBA development.

    The tool was designed to streamline the art pipeline for Resonant, reducing manual tile conversion and ensuring compatibility with VRAM constraints and palette limitations.

    Technologies: Python, graphics processing, palette quantization, tile slicing automation.

    Skills & Focus Areas

    I enjoy building mechanics that change how the player makes decisions. I focus on clean, bug-resistant gameplay code, readable systems, and levels that teach through design rather than long text.

    Gameplay Programming

    Player abilities, enemy behaviors, state machines, hit detection, knockback, cooldowns, and timing-sensitive systems.

    Combat Feel & Tuning

    Balancing responsiveness with clarity: attack windows, telegraphing, invulnerability frames, and feedback loops.

    Systems & Architecture

    Rooms designed to teach mechanics naturally: safe introduction, forced-use scenarios, escalation, and payoff challenges.

    Tracking timing issues, physics edge cases, input desync, and reducing “it sometimes breaks” behavior.

    Clear project writeups, short design pitches, controls, and playable builds (WebGL or downloadable).
