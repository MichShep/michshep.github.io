Personal Project · Aug 2025 – Present

GBA Bare-Metal Game Engine

A bare-metal game engine written in C and ARM assembly for the ARM7TDMI-based Game Boy Advance, directly configuring memory-mapped display, interrupt, and DMA registers without an operating system.

Key Features

VBlank-Synchronized Rendering

Sustained a 60 FPS rendering loop within 256 KB of EWRAM by synchronizing graphics updates with VBlank interrupts and using DMA for sprite and asset transfers.

C ARM Assembly DMA

Lifetime-Aware Memory Allocators

Designed lifetime-aware memory allocators using stack-based arenas for transient UI and text objects and reusable free-list memory pools for dynamic entities, providing predictable allocation on memory-constrained hardware.

Memory Management Embedded

Python Asset Pipeline

Built a Python CLI asset pipeline that converts images into GBA-compatible C code, packed tile and palette data, and tilemaps, with deduplication, LZ77 compression, and content-based caching, reducing asset iteration time by 80%.
