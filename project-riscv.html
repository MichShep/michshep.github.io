Team Project (5-person team) · Aug 2025 – Nov 2025

Superscalar RISC-V Processor

A 3-way superscalar, out-of-order RV32IM processor in SystemVerilog with register renaming, dynamic scheduling, speculative execution, and precise in-order retirement, built collaboratively with a five-person team.

Key Features

Branch Prediction & Recovery

Contributed to the integration of a tournament branch predictor with early branch recovery, improving pipeline efficiency on mispredicted paths.

SystemVerilog Branch Prediction

Caching & Memory Ordering

Implemented banked instruction caching with prefetching and a victim cache, plus a load-store queue with byte-level store-to-load forwarding.

RTL Caching Memory Ordering

Verification

Verified the processor through module-level testbenches and automated comparisons against a golden ISA simulator, passing all provided benchmarks and achieving a synthesized 20 ns clock period.
